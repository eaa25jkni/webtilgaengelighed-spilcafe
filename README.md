# Eksamens projekt - Sustaniable web

## Beskrivelse
Projektet Sustainable Web er et redesign af Spilcaféens spiloversigt med fokus på: 
- Bæredygtigthed
- Webtilgængelighed
- Responsivt design
- Forretningspotentiale

Projektet tager udgangspunkt i en tidligere løsning af Spilcaféens spiloversigt fra 1. sem. Den blev analyseret gennem webaudits og brugertests, hvoraf anbefaleringer til forbdringer indenfor de fire områder blev lavet. 

Målet var at identificere og forbedre udfordringer inden for performance, tilgængelighed for at skabe en mere bæredygtig, intuitiv og inkluderende spiloversigt.
